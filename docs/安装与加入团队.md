# 安装与加入团队

适用于 Research OS **1.0.0**，以下步骤使用 macOS 和个人版 OneDrive。

以下命令安装 `v1.0.0` 正式版。其他已发布的标签见仓库的 [Releases 页面](https://github.com/LinyingL/research-os/releases)。

所有人先完成安装。收到项目邀请的成员继续看「成员加入」，项目负责人继续看「PI 设置团队」。

[English](install-and-join.en.md) · [项目介绍](../README.md)

## 安装

准备一台 Mac（macOS 12 或以上）、个人版 Microsoft 账号和网络连接。

### 1. 安装 OneDrive

在 App Store 安装 Microsoft OneDrive，用你的 Microsoft 账号登录。完成后，访达侧边栏会出现「OneDrive」。后续共享邀请使用这个账号的邮箱。

### 2. 安装苹果命令行工具

按 Command + 空格，搜索并打开「终端」，运行：

```bash
xcode-select --install
```

按弹窗提示完成安装。若显示 `already installed`，继续下一步。

### 3. 安装 uv

uv 负责安装 Research OS 和所需的 Python 环境。在终端运行：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

出现 `everything's installed!` 后，关闭并重新打开终端，再检查版本：

```bash
uv --version
```

显示版本号即可。

### 4. 安装 Research OS

```bash
uv tool install git+https://github.com/LinyingL/research-os@v1.0.0
```

成功后会显示 `Installed 2 executables: rce, researchos`。其他提示见文末「常见问题」。

### 5. 创建并打开应用

```bash
researchos app
```

应用位于 `~/Applications/Research OS.app`。按 Command + 空格搜索「Research OS」并打开；也可以在访达的「前往」「个人」「应用程序」中打开。

首次访问「文稿」或 OneDrive 时，按 macOS 提示允许访问。

## 成员加入

### 1. 把公钥发给 PI

1. 点击「从公盘加入项目…」。
2. 在「1. 我是谁」填写名字和 OneDrive 账号邮箱，点击「保存」。
3. 在「2. 我的公钥」点击「生成我的公钥」。
4. 点击「复制」，把以 `ssh-ed25519` 开头的整行文字和邮箱发给 PI。若显示「请手动选中复制」，选中文字后按 Command + C。

发送后可点击「关闭」，等待 PI 的共享邀请。发送的是公钥，私钥保存在本机。

### 2. 接受两个共享邀请

PI 会分别共享两个 OneDrive 文件夹：

| 文件夹 | 用途 | 你的权限 |
| --- | --- | --- |
| 「已发布」 | 团队正式版本 | 可以查看 |
| 以你的邮箱命名的文件夹 | 你的提议 | 可以编辑 |

分别打开两封邀请邮件，在 OneDrive 网页版点击「添加快捷方式到我的文件」（部分页面显示「添加到我的文件」）。也可以从网页版的「共享」「与我共享」找到它们。

在访达的 OneDrive 中找到这两个文件夹，分别右键选择「始终保留在此设备上」，等待下载完成。

### 3. 选择文件夹并加入

回到「从公盘加入项目…」，在「3. 公盘和工作副本」中点击「选择…」，填写：

| 字段 | 选择的位置 |
| --- | --- |
| 「公盘文件夹，或 PI 共享给你的「已发布」文件夹」 | OneDrive 中的「已发布」 |
| 「你自己的提议文件夹」 | OneDrive 中以你的邮箱命名的文件夹 |
| 「工作副本放在哪里」 | 本机上新建的空文件夹，例如「文稿/论文_我的副本」；放在 OneDrive 之外 |

点击「查看」，检查文件夹和权限。页面会显示「PI 公钥指纹」，以 `SHA256:` 开头。通过电话或当面与 PI 核对；一致后点击「核对无误，加入」。若不一致，先联系 PI 确认。

### 4. 同步团队版本

在「成员」的「公盘与同步」中点击「同步」。显示「已经是最新的正式版本」，且「团队」中有你的名字，即可开始工作。若还没有你的名字，请 PI 加入成员名单并发布，再同步一次。

## PI 设置团队

### 1. 打开项目，建立成员名单

1. 点击「添加项目…」「选择文件夹…」，选择项目文件夹。查看扫描范围后，点击「加入并扫描」。
2. 点击左侧栏顶部的项目名称，选择「开始协作…」，打开「成员」页。在「我是谁」填写名字和 OneDrive 账号邮箱，点击「保存」。
3. 在「开始协作」点击「建立成员名单」。

只有你一个人时，左侧栏没有「成员」和「提议」。建立成员名单之后，这两项会出现在左侧栏。

将 `~/.researchos/keys` 备份到安全位置。私钥丢失后需要换钥匙，成员也需要重新核对指纹。

### 2. 设置公盘，发布第一版

1. 在 OneDrive 新建团队文件夹，放在项目文件夹之外，右键选择「始终保留在此设备上」。
2. 在「成员」的「公盘」中点击「选择…」，选中该文件夹，再点击「设为公盘」。
3. 点击「发布」。Research OS 会创建「已发布」文件夹并写入第一版。

### 3. 添加成员，分配共享权限

1. 收到成员的公钥后，在「添加成员」填写邮箱和名字，将公钥粘贴到「公钥文字」。若收到的是文件，在「公钥文件」旁点击「选择…」。
2. 点击「添加成员」，再点击「发布」。成员的提议文件夹会出现在公盘的「提议/成员邮箱」下。
3. 打开 OneDrive 网页版（[onedrive.live.com](https://onedrive.live.com)），分别选中文件夹，点击「共享」，按下表设置权限并发送邀请。

| 共享的文件夹 | 接收人 | 权限 |
| --- | --- | --- |
| 「已发布」 | 团队成员 | 可以查看 |
| 「提议/成员邮箱」 | 对应成员 | 可以编辑 |

只共享这两个文件夹，不共享公盘根目录或整个「提议」目录。

### 4. 核对指纹

在「成员」的「我的公钥」中找到「指纹：」。成员加入时，通过电话或当面核对这串以 `SHA256:` 开头的内容。

## 日常使用

### 成员提交改动

1. 在「成员」点击「同步」，然后在本地工作副本中修改文件。
2. 打开「提议」，在「提交提议」中选择「新的尝试」「修改研究判断」「变量定义」或「只有文件」，填写说明，点击「查看将要发送的内容」。
3. 核对文件列表。若调整了勾选，先点击「按勾选的文件重新查看」，再点击「发送提议」。
4. 在「提议」查看「提议中」「已批准」或「已退回」的状态及理由。显示「已批准，待同步」后，再同步一次。

提议和答复需要等待 OneDrive 同步。备注、连线确认，以及「归入尝试」「添加文件」「指定生成它的脚本」的改动随同步发送，不单独审批；研究路线之间的连线需要 PI 审批。

### PI 处理提议

打开「提议」，查看改动后选择：

| 操作 | 结果 |
| --- | --- |
| 「批准并加入」 | 改动写入正式版本，并发布新版本 |
| 「退回并说明」 | 写明理由，交由成员修改 |
| 「讨论」 | 留下意见，提议保持打开 |

直接修改正式项目后，在「成员」点击「发布」。成员下次同步即可收到更新。

## 同一个文件两边都改过

PI 看到「两边都改过」时，这份提议暂时不能批准。请成员先同步、比较两份内容，再重新提交。尝试表按行比较，其他行的修改不会阻止当前行的提议。

成员同步时，本地文件会保留，正式版本放在旁边，例如 `16-build.official.py`。在「成员」的「放在旁边的正式版本」中查看差异，将需要的内容保留到原文件，删除 `.official` 副本，再提交提议。

## 常见问题

### 提示 `is not on your PATH`，或找不到 researchos 命令

运行下面的命令，然后重新打开终端：

```bash
uv tool update-shell
```

### 安装时出现 `Git operation failed` 或 `could not read Username`

检查网络连接、安装命令中的仓库地址及 GitHub 访问权限。仍无法安装时，将终端最后几行报错发给 PI 或提交到项目的 [Issues](https://github.com/LinyingL/research-os/issues)。

### 只显示 `Installed 1 executable: rce`

安装到的是旧版。先卸载，再按「安装 Research OS」中的地址重新安装：

```bash
uv tool uninstall rce
```

### 应用无法访问「文稿」

打开「系统设置」「隐私与安全性」「文件和文件夹」，允许 Research OS 访问「文稿文件夹」，然后重新打开应用。

### 共享文件夹只有云朵图标，或提议还没出现

在访达中右键选择「始终保留在此设备上」，等待 OneDrive 下载和同步完成。成员还需在 Research OS 中点击「同步」。

## 更新

在终端依次运行：

```bash
uv tool install --force git+https://github.com/LinyingL/research-os@v1.0.0
```

```bash
researchos app
```

安装后运行 `researchos app`，让应用使用最新菜单和保存所需的会话。重新打开应用。如果 macOS 再次询问文件访问权限，按提示允许。
