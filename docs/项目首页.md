# 项目首页

本说明对应 0.2.0 之后的开发版本。

点击“新建项目…”，填写名称并选择保存位置，即可进入项目首页，直接写研究问题和计划。
软件会自动准备一张空白尝试表，之后需要时再开始记录尝试；不用先导入历史。

已有研究文件夹仍用“添加项目…”打开。浏览首页不会修改原有文件；第一次保存方案时才
建立写作文件，原来的尝试表保持不变。

## 写方案、笔记和结果

内容可以自由写，随时修改。点击“保存”，或在写作区按 Command-S。“预览”可以查看
标题、列表、表格和本地图片。

“写笔记”适合想法、讨论和待解决的问题；“整理结果”用来把图表、发现和解释放在一起。
这些记录可以独立存在，也可以按需关联研究尝试。

下方的任务清单可以填写负责人和日期，也可以只记一句接下来想做的事。任务没有固定
顺序，可以修改、完成或移除；不用先完成任务才能继续写作或记录研究。

## 引用外部工具产生的文件

继续用 Stata 等工具编辑代码、运行分析。把结果保存在项目目录后，展开“关联文件与
尝试”，点击“刷新文件”，选择文件并插入引用。支持的图片可以直接预览，文件仍放在
原处，不会再复制一份。

引用表示你选择了这个文件，不代表软件已经确认脚本运行过或生成了某项结果。

## 保存与审批

方案、笔记和结果以 Markdown 保存在项目的 `research/` 目录，任务保存在
`research/tasks.json`。保存修改时会保留之前的版本。如果文件同时被别的编辑器修改，
软件会保留当前草稿，并提示重新打开文件处理差异。
点击“修改历史”可以查看已保存的版本和差异。

团队成员先保存到自己的工作副本。点击“提交修改”后，检查预览、填写说明，再发送给
PI。结果记录引用的本地文件也会列入预览，可以核对是否需要一起提交。PI 批准后才
进入正式项目。单人项目保存后直接生效。
